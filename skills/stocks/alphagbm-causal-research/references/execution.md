# 执行边界与离线计算

本包是独立研究方法，不附带内部研报、账号凭据、行情或私有API。使用用户提供的授权文件及宿主已开放的检索/原件读取/计算工具；不得假装存在其他工作区的fact-check-gate、TOOLS.md或脚本。

使用当前宿主自身的文件读取、检索和计算工具，不要求另装或调用Codex、Claude等其他AI客户端。将`<skill-dir>`解析为本次读取的SKILL.md所在目录；脚本路径不依赖当前工作目录。缺少Python或执行权限时标注「计算未执行」，不得把心算或转述样例写成脚本回执。

区分「原生已安装技能」与「当前会话按文件执行的方法」：只有宿主实际提供注册/启用成功证据时才声称安装成功；下载、解压或建一个目录不等于注册，也不保证新会话自动发现。没有原生安装入口时，可在用户授权下读取本包并按文件执行，但必须标明这种使用方式。不要为了验证本宿主兼容性转用其他宿主。

AlphaGBM Agent的`search_research_reports`/`read_research_report`若实际开放，可作机构线索入口，但结构化记录不是原PDF。遵守登录、额度和每条记录权限；安装本包不开放这两个内部端点。查看实际工具列表，缺少原件读取能力时请用户提供原件或交付待核项。搜索摘要不足以完成独立核验。

内部材料不得上传到搜索引擎或公共仓；只用公开实体和字段构造外部查询。未知发布许可默认不可公开，用户拥有方法不代表拥有第三方研报的公开派生许可。对外输出须由宿主执行权限门禁，不把提示词当安全控制。本包不自动保存、发布或导出研究。

计算器只读stdin、输出JSON，不联网、不执行表达式、不读取路径。输入最多16KB，1—32个十进制字符串，各至多15位整数、8位小数；输入必须已对齐同一单位。支持`sum`、`difference`、`ratio`、`percent_change`。后两者不自动辨别输入的实际/预测性质，也不自动验证来源。比例/增速输出用28位Decimal上下文；不是无限精度计算。

合成示例，不是真实公司数据：

```json
{"operation":"difference","values":["80","110"],"unit":"CNY million","evidenceIds":["E1","E2"]}
```

输出结果为−30，含输入、单位、来源编号及已执行标记。`difference`只接受两项，按第一项减第二项；`ratio`第一项除第二项；`percent_change`输入为当前值、基期值，基期须大于0，结果为百分数。未知值、NaN、Infinity、零分母和不支持的操作均报错，不产生成功回执。

计算结果只证明给定输入的算术。手工转录原表后仍需检查数字、页码、列头、单位和符号；脚本通过不证明整个投资论点成立。
