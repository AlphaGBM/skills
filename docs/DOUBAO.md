# 在豆包工作中使用 AlphaGBM

不需要另外安装 Codex。用现有的 **产业因果研究** 方法研究你提供的材料，或在你明确授权后检索公开原件：追问机制、核验数字、比较竞争解释、寻找反证。它不是拆股演示，也不是自动选股或收益预测。

## 获取入门包

- [下载完整技能 ZIP](https://github.com/AlphaGBM/skills/releases/download/skills-onboarding-v2/alphagbm-causal-research.zip)
- [下载文件校验清单](https://github.com/AlphaGBM/skills/releases/download/skills-onboarding-v2/alphagbm-causal-research.manifest.json)
- [版本说明与源码](https://github.com/AlphaGBM/skills/releases/tag/skills-onboarding-v2)

ZIP 包含原技能的 `SKILL.md`、计算器、三份参考资料、可忽略的其他客户端元数据，以及 MIT 许可。没有账号、内部研报、API Key、收费运行器或安装其他客户端的程序。安装包不增加目录中的技能数量。

本版 `skills-onboarding-v2` 保留[简短介绍与语言规则](INTRODUCTION.md)，增加[手机友好的结果排版](PRESENTATION.md)和「查利润质量」入口：先结论、最多三条发现、反证，再给核验底稿。原有授权分流、严格JSON和计算器保持不变。此前发布资产不修改，已下载的包不会自动升级。

**状态：入门包提供中；豆包原生导入、启用和跨会话自动调用尚未验收。** 支持导入的客户端版本、账号入口和权限以你实际使用的豆包工作为准，不能把普通豆包聊天窗口等同于具备技能管理的工作环境。

## 先选资料来源，不用自己备齐所有资料

- **我有材料**：上传有权处理的文件，先研究已有原件。缺字段再补，不必先收集多年财报和整套行业报告；未授权时不额外联网。
- **我没有材料**：让豆包先问「上传材料／授权公开原件检索」。选择后者后，豆包用自己的可用工具查公司官网、交易所和法定披露原件，不再要求你先把全部文件找齐。没有联网或全文读取工具时，只请求最少替代材料。

「默认材料可用」不是联网许可，也不是文件确实存在的证明。已经明确授权公开检索的，不重复询问同一授权；新增收费、登录、私有数据或材料外传仍需另行同意。

可以直接发送以下**公开资料模式**指令；发送这段即明确授权其中限定的检索，不必再逐份批准公开原件：

```text
研究问题：[填写问题]。研究截止日：[YYYY-MM-DD]。
允许你用当前宿主自己的工具，检索公开可访问的公司官网、交易所和法定披露原件。
不访问AlphaGBM私有研报库或收费接口，不登录、不付费、不外传我的材料；遇到这些需求先问我。
请用AlphaGBM产业因果研究方法，把问题缩成一个关键机制，先取1—3份必要原件开展一轮研究，不要求我先备齐整套材料。
只使用不晚于截止日发布的资料，保留来源、页码/表格、期间和单位，实际运行计算并查找反证；没拿到的字段写缺失。
交付结论、证据、计算回执、竞争解释、实际反证动作、待核项和被推翻的结论。不要给买卖指令。
```

## 路径一：你的豆包工作有技能导入入口

1. 下载 ZIP，在豆包工作自己的技能管理中选择导入本地技能包。不要把普通聊天附件上传当作技能注册。
2. 确认技能列表实际出现 `alphagbm-causal-research`，并已启用。保存成功提示；若失败，保留原始报错，不要安装 Codex 绕过。
3. 新开会话，选择上面的公开资料模式，或附上你有权使用的材料后发送：

> 用 AlphaGBM 产业因果研究方法分析这些材料。先明确研究问题和截止日，再给出追问路径、原始证据位置、实际数字计算、竞争解释、反证和待核项。先只用我提供的材料；需要外部查询或额外消耗额度时先问我。不要给买卖指令。

没有材料时按「资料来源」提供两种选择，不应只退回大材料清单、编造事实或用合成示例冒充研究。资料不完整可以交付部分验证结果，但必须列明缺口。

## 路径二：有云电脑，但没有原生技能导入入口

这时仍可按**本次会话的文件工作流**使用；不是原生安装成功，不保证下次会话自动记住。把下面一段交给豆包：

```text
请用你自己的云电脑和工具使用 AlphaGBM 产业因果研究方法，不要安装或调用 Codex、Claude、Cursor 等其他AI客户端。

下载完整包：
https://github.com/AlphaGBM/skills/releases/download/skills-onboarding-v2/alphagbm-causal-research.zip
同时下载校验清单：
https://github.com/AlphaGBM/skills/releases/download/skills-onboarding-v2/alphagbm-causal-research.manifest.json

在新的工作目录核对ZIP的SHA-256，安全解压（拒绝绝对路径、越界路径和符号链接），核对包内各文件哈希，读取SKILL.md及所需references。不要改写文件或从未知位置补脚本。下载或校验失败就报告原始错误。

若没有原生导入入口，请明确标注“本次会话按文件执行”，不要声称已经注册技能。确认研究问题、截止日和资料来源，只问尚未明确的事项。有授权文件先读文件；没有文件且未授权检索时，一次让我选择“上传材料／授权公开原件检索”。我已明确授权的公开检索直接执行，不重复问同一授权，也不要只给一份大材料清单。

实际计算请使用随包scripts/calculate.py，保留输入、命令、退出码及输出；没有Python或执行权限就标注计算未执行。不得把心算冒充执行。

默认只用我提供的材料；我明确选择公开资料模式后，按限定范围使用你自己的检索工具。不访问AlphaGBM账户或收费接口，不索要API Key，不下单，不修改我的文件；超出已有授权的检索、登录、付费或外传材料先征得同意。没有检索工具就说明缺项，不虚构取证。不要把下载阶段联网或宿主模型调用说成全程离线。
```

从旧版升级请将skills-onboarding-v2下载到新目录、校验新的manifest并重新读取方法，不覆盖旧材料；不要混用两个版本的包与清单。校验成功后直接继续真实研究，不重复用合成算式证明安装。

如果没有云电脑或文件读取能力，可以把方法文字作为对话参考，但不能声称运行了计算器，也不属于技能安装验收。

## 交付应该是什么样

| 内容 | 验收点 |
|---|---|
| 研究问题与竞争解释 | 不是预设看多/看空，至少说明另一种解释 |
| 追问路径 | 为什么问、取了什么证据、结果如何改变下一问 |
| 证据表 | 文件、页码/表格、期间、单位；没有原件就写未核 |
| 数字计算 | 输入、证据ID、公式、实际执行回执；口径不兼容不相加 |
| 反证与失效条件 | 哪些事实会推翻当前判断，哪些尚未取得 |
| 结论边界 | 已验证/部分验证/未验证，不给无依据概率或收益保证 |

计算器只支持加总、差额、比例和变化率；不是估值引擎，不自动验证输入事实。方法可用于用户授权的文件；缺少外部原件时不能冒称完成独立核验。

## 权限、费用与当前限制

- 本包本身不调用 AlphaGBM 服务，不消耗 AlphaGBM 研究额度。豆包自身的模型、工具或检索仍可能有用量限制或费用。
- 不要求用户在聊天中提交密钥。安装方法不开放 AlphaGBM 内部研报库、付费研究接口或生产工作流。
- 官方开发者指南要求外部服务通过平台支持的连接器接入；本包没有实现这类账号连接器，不应通过复制其他技能的 `run.py` 绕过它。
- 本地计算不需要网络，但联网研究并不等于整个会话离线。无法强制断网时如实说明，不为测试关闭安全保护。
- 仅上传你有权交给豆包处理的材料；不要上传客户隐私、账户信息或未经许可的第三方研报原文。

本次来源核对：2026-11-28，豆包[官方技能接入指南](https://open.doubao.com/document/doubao-developer-guide/skill-integration-guide)。平台提供机制不等于本包已完成豆包客户端验收。公开上架、平台审核、原生安装和跨会话自动触发分别记录，不互相替代。

## 维护与复现

### 已做与未做的验证（2026-11-28）

- v2本地120项离线测试通过，11项包测试覆盖ZIP内容、哈希、独立运行、引用闭合、缓存/额外运行器排除、缺文件及符号链接拒绝，以及资料入口文案与版本链接约束。测试进程禁止联网，未提供研究凭据；文案断言不等于客户端行为验收。
- 安装器只读发现仍为28项；没有另增一个重复技能。独立ZIP解压后计算器可运行，技能元数据校验通过。
- fresh-context代理仅拿到解压技能及两份虚构材料的摘录，没有预期答案。它实际执行3次本地计算，区分经营现金流与未提款授信、人民币半年实际数与美元全年预测，并将缺完整原件的结论标为部分验证。
- v2独立代理用解压后的方法模拟四种入口：未授权且无文件、已授权公开检索、无联网工具、仅文件且禁网。前三种只验证下一步回复和拟调用，不执行联网；第四种实际执行两次合成计算，保留口径假设与未核原件。不能据此声称真实公司研究或豆包客户端复测通过。
- 上一项是方法执行测试，**不是豆包客户端或豆包模型的验收**。原生导入、启用、跨会话自动发现和平台上架均未验证；模型推理本身也不被承诺离线或免费。

源码仍是原有的 [产业因果研究包](../skills/stocks/alphagbm-causal-research/)，没有分叉一套方法。构建只收录白名单文件，排除缓存、凭据、用户材料和其他运行器：

